# Student Score Prediction

## Project Description

This project predicts a student's score based on the number of hours studied.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Dataset

The dataset contains student study hours and scores.

## Machine Learning Model

Linear Regression is used to predict student scores based on study hours.

## Model Evaluation

The model is evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* R^2 Score

## Prediction

The trained model takes study hours as input and predicts the student's score.

## Project Outcome

A simple machine learning prediction system was successfully created to predict student scores based on study hours.
